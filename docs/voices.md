# Движки озвучки

Движок выбирается полем `voice.engine` в `reel.yaml`. Все движки работают одинаково: делают дубли,
Whisper сверяет каждый дубль с текстом сценария, лучший дубль копируется в `build/voice/master.wav`.
Список дублей со сверкой лежит в `takes.json`, выбранный дубль — в `choice.json`.

## Сравнение

| | `f5` | `qwen3` | `piper` | `file` |
|---|---|---|---|---|
| Модель | F5-TTS + веса `Misha24-10/F5-TTS_RUSSIAN` | Qwen3-TTS `Qwen/Qwen3-TTS-12Hz-1.7B-Base` (или `0.6B-Base`) | Piper, голоса `ru_RU-*-medium` | своя запись |
| Качество | высокое, клон тембра по эталону | высокое, клон тембра по эталону, живая интонация | ровное, заметно «синтетическое» | какое запишете |
| Ударения | RUAccent + ручные правки `voice.accents` (знак «+») | модель ставит сама; «+» по умолчанию убирается | модель ставит сама | ваши |
| Скорость | секунды на дубль на видеокарте | на видеокарте; 0.6B быстрее 1.7B (замеров в репозитории пока нет) | быстро даже на процессоре | без синтеза |
| Видеокарта | нужна (на процессоре очень медленно) | нужна (на процессоре очень медленно) | не нужна | не нужна |
| Лицензия весов | CC-BY-NC 4.0 | Apache-2.0 | `denis`, `dmitri` — CC0; у других голосов смотрите `MODEL_CARD` | ваша |
| Коммерция | **нет** | да | да (с голосами CC0) | да, если у вас есть права на запись |
| Когда брать | некоммерческие ролики, когда нужен точный контроль ударений | коммерческие ролики, клон голоса | черновик, проверка таймингов, эталоны для `f5`/`qwen3` | готовая дикторская озвучка |

Клонировать чужой голос можно только с согласия его владельца. Подробнее о лицензиях — в [NOTICE.md](../NOTICE.md).

## `f5` — F5-TTS

```yaml
voice:
  engine: f5
  voices: [denis, dmitri]        # эталоны assets/ref-<голос>.wav; нет файла — синтез Piper
  seeds: [7, 11, 31]             # голоса × seeds = 6 дублей
  ref_text: "Утром на площади пусто: …"   # что звучит в эталоне
  accents: {Паули: "Па+ули"}     # ручные правки ударений
  speed: 1.0
  nfe_step: 32
  min_ratio: 0.98
```

Веса ищутся в `models/f5-ru/` (или в папке из переменной `TTS_MODELS`). Установка: `pip install f5-tts ruaccent`.

## `qwen3` — Qwen3-TTS

```yaml
voice:
  engine: qwen3
  voices: [denis, dmitri]        # эталоны — как у f5: assets/ref-<голос>.wav или синтез Piper
  seeds: [7, 11, 31]
  ref_text: "Утром на площади пусто: …"   # расшифровка эталона: Qwen3 клонирует по паре «звук + текст»
  qwen_model: Qwen/Qwen3-TTS-12Hz-1.7B-Base   # или Qwen/Qwen3-TTS-12Hz-0.6B-Base, или путь к папке
  qwen_language: Russian         # Russian, English, … или Auto
  qwen_keep_accents: false       # true — прогнать RUAccent и оставить «+» в тексте
  min_ratio: 0.98
```

Установка (рекомендуется Python 3.12; PyTorch ставится отдельно под вашу версию CUDA):

```bash
pip install -U qwen-tts
pip install -U flash-attn --no-build-isolation   # по желанию: быстрее и меньше памяти на видеокарте
```

Веса скачиваются с Hugging Face при первом запуске. Для работы без сети скачайте их заранее
в `models/<имя модели>`, тогда конвейер найдёт их сам (папку `models` можно сменить переменной `TTS_MODELS`):

```bash
huggingface-cli download Qwen/Qwen3-TTS-12Hz-1.7B-Base --local-dir models/Qwen3-TTS-12Hz-1.7B-Base
```

Как это работает:

- Эталон голоса берётся так же, как для `f5`: файл `voice.ref` или Piper зачитывает `ref_text`
  (24 кГц, моно). Свой эталон тоже лучше сохранить в 24 кГц моно, а `ref_text` должен точно совпадать
  с тем, что в нём звучит.
- Знаки ударения «+» Qwen3-TTS не понимает, поэтому они убираются из сценария и из `ref_text`.
  С `qwen_keep_accents: true` текст размечается RUAccent и уходит в модель вместе с «+». Это эксперимент:
  как модель читает такой текст, не проверено.
- Своего параметра seed у Qwen3-TTS нет. Перед каждым дублем конвейер задаёт seed для `torch`,
  `numpy` и `random`, поэтому дубли повторяются на той же машине и версии библиотек.
- Если ударение в слове всё равно неверное, добавьте seeds или перепишите фразу. Знаки «+» тут не помогут.
- На видеокарте модель загружается в bfloat16 (с FlashAttention 2, если он установлен), на процессоре — в float32.

## `piper` — Piper

```yaml
voice:
  engine: piper
  voices: [denis, dmitri]
  piper_models: models/piper     # ru_RU-<голос>-medium.onnx + .onnx.json (или переменная PIPER_MODELS)
```

Один дубль на голос, seeds не используются. Установка: `pip install piper-tts`.
Голоса — из `rhasspy/piper-voices` (`ru/ru_RU/<голос>/medium/`).

## `file` — готовая озвучка

```yaml
voice:
  engine: file
  file: assets/voice.wav         # любой формат, который читает ffmpeg; приводится к 48 кГц
  words: assets/words.json       # необязательно: готовые таймкоды [{"w", "s", "e"}]; иначе распознаёт Whisper
```

Если установлен faster-whisper, запись сверяется со сценарием. Без него сверка пропускается, и запись
принимается как есть.
