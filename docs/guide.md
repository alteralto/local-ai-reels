# local-ai-reels: стек и инструкция

Инструкция описывает, как сделать вертикальный ролик (1080×1920, 25–30 с) с озвучкой, субтитрами, чертёжной
графикой и музыкой. Всё, кроме сценария, работает локально и без платных сервисов. Нужна видеокарта NVIDIA
с CUDA; проверено на карте уровня RTX 3060 (12 ГБ). Рендер 25-секундного ролика занимает около минуты.

Полный код всех скриптов —
в приложении в конце документа. Каждый листинг нужно сохранить в файл с указанным именем, все файлы в одну папку.
Образец сцен и анимации — `build.py` из примера «Поводок».

> В репозитории скрипты уже лежат в `scripts/`, а пример озвучки с таймкодами — в `example/`. PDF-версия
> этой инструкции с кодом всех скриптов в приложении — `docs/guide.pdf`, её собирает `tools/build_pdf.py`.

## Если документ читает ИИ-агент

Задача: собрать вертикальный ролик по шагам 1–8 раздела «Пошагово».

1. Создать рабочую папку, в ней `voice/` и `music/`. Сохранить листинги из приложения в файлы с указанными
   именами: `.py` и `.sh` — в корень папки.
2. Ставить зависимости по разделу «Установка». Модели скачиваются при первом запуске, кроме весов F5:
   их скачать заранее (шаг 2 установки).
3. Сценарий: 4 блока, не больше 60 слов, каждый блок понятен без соседних. Проверка — `python texts.py`.
4. Останавливаться и показывать человеку: сценарий до озвучки, `master-acc.json` после разметки ударений,
   выбранный дубль, кадры `snapshot` до рендера.
5. Под новый сюжет в `build.py` переписать `CUTS`, `SCRIPT`, `SCENES`, `ANIM`, подпись источника и финальную карточку.
   Остальной код не трогать.
6. Ролик готов, когда выполнены все условия:
    - 1080×1920, 30 fps;
    - громкость около −17 LUFS (`bash finish.sh check`);
    - Whisper по готовому файлу распознаёт сценарий дословно;
    - в `hf.sh lint` нет ошибок.

## Стек

| Этап | Инструмент | Что делает | Лицензия |
|---|---|---|---|
| Сценарий и факты | LLM (Claude Opus 5.5) + `texts.py` | 4 блока, не больше 60 слов; скрипт считает слова | — |
| Эталон голоса | Piper, голоса `denis` и `dmitri` (medium) | синтетический образец речи на 8–10 с, чтобы не клонировать живого человека | CC0 |
| Ударения | RUAccent (`turbo3.1` + словарь) | ставит `+` перед ударной гласной | см. репозиторий |
| Озвучка | F5-TTS 1.1 + русская модель `Misha24-10/F5-TTS_RUSSIAN` (`F5TTS_v1_Base_v2`) | клонирует голос эталона и читает размеченный текст | **CC-BY-NC**, только некоммерческое использование |
| Сверка и таймкоды | faster-whisper `large-v3-turbo` | проверяет дубли на ошибки, выдаёт время каждого слова | MIT |
| Монтаж | HyperFrames 0.8.75 (HeyGen, open source) + GSAP 3.14 | рендерит HTML в MP4: сцены, субтитры, звук по таймлайну | см. репозиторий |
| Графика | SVG-код в `build.py` | планы, изохроны, аксонометрия; чертёж точнее, чем у генераторов картинок | — |
| Музыка | MusicGen-small (Meta) | фон около 27 с по текстовому описанию | **CC-BY-NC** (веса) |
| Субтитры и переходы | `polish.py` (GSAP) | фразы по 3–5 слов с подсветкой слова, уход сцены перед склейкой, полоска прогресса | — |
| Звуковые эффекты | numpy + scipy | синтез щелчка замка, «вжуха» на склейках и других звуков | — |
| Сведение, постер, проверка | ffmpeg 8 | громкость −18 LUFS, постер в первом кадре, замеры | — |

У F5 и MusicGen некоммерческие лицензии. Для некоммерческих проектов это не мешает. Для коммерческого заказа их нужно
заменить: озвучку сделать на Qwen3-TTS 0.6B (Apache-2.0), музыку взять стоковую или свою.

## Установка

1. Python-окружение с PyTorch под CUDA, затем `pip install f5-tts ruaccent faster-whisper transformers scipy`.
2. Веса озвучки `Misha24-10/F5-TTS_RUSSIAN` с Hugging Face — в папку `models\f5-ru\`. Скрипт ждёт файлы
   `F5TTS_v1_Base_v2\model_last_inference.safetensors` и `F5TTS_v1_Base\vocab.txt`. Скрипты запускаются
   из разных папок (`voice\`, `music\`), поэтому в переменной `TTS_MODELS` указать **полный** путь к `models`.
3. Piper (`pip install piper-tts`) и голоса `ru_RU-denis-medium`, `ru_RU-dmitri-medium` из `rhasspy/piper-voices`.
4. Node.js 22+ и ffmpeg в PATH. HyperFrames скачивается сам при первом запуске `hf.sh`.
5. RUAccent, Whisper и MusicGen скачивают модели при первом запуске. Папку моделей RUAccent задаёт `RUACCENT_DIR`
   (тоже полный путь).
6. Все команды ниже запускаются в bash (на Windows — Git Bash). `python` — интерпретатор из окружения шага 1.

## Скиллы и источники

Скиллы агентов использовались как руководства: из их инструкций взяты правила. Отдельными командами в агенте
они не запускались.

- **brag-slim** из [latent-spaces/brag](https://github.com/latent-spaces/brag). Это скилл для коротких
  промо-роликов, сделанных моделью целиком. Из него взято:
    - крючок решает всё: первые 2 секунды планируются первыми;
    - форма «крючок → раскрытие → 2–3 сильных пункта → панчлайн» как отправная точка, а не шаблон;
    - музыка и эффекты сводятся как один трек: эффекты в той же тональности и тише музыки, без резких пиков;
    - постер — самый сильный кадр, где текст уже полностью появился. Его вшивают **вместо** кадра 0, а не
      добавляют новым кадром, чтобы длительность и синхрон со звуком не сдвинулись.
- **skills.sh** — каталог скиллов агентов; поиск по запросу `hyperframes` показывает, как HyperFrames используют
  другие.
- **skillry.dev/ai-videos/opus-5-5** — примеры роликов, которые Opus 5.5 сделал сам. Ориентир по уровню и подаче.
- **HyperFrames README** (heygen-com/hyperframes) — формат композиции: `data-start`, `data-duration`,
  `data-media-start`, `window.__timelines`.
- **Рецепт озвучки F5 + RUAccent**: эталон 8–10 с плюс тишина в конце, полная разметка ударений, отбор дублей
  через Whisper.

## Свой голос

F5-TTS клонирует любой голос по образцу на 8–10 секунд, поэтому вместо голосов Piper можно взять свой.

**Откуда взять образец:**

- **Свой голос.** Записать на телефон в тихой комнате без эха и музыки. Прочитать 1–2 фразы ровно, в темпе
  будущего ролика: как прочитан образец, так будет звучать и ролик.
- **Другие голоса Piper.** Перед использованием проверить лицензию в `MODEL_CARD` голоса. Например, у `denis`
  и `dmitri` — CC0, у `ruslan` — CC-BY-NC-SA, у `irina` лицензия не указана.
- **Голос другого человека** — только с его согласия.

**Подготовка образца** (обрезать до 8–10 с, моно, 24 кГц, выровнять громкость, добавить тишину в конце):

```bash
ffmpeg -i запись.m4a -ss 2.0 -t 9 -ac 1 -ar 24000 -af "highpass=f=80,loudnorm=I=-20,apad=pad_dur=0.45" ref-my-p.wav
```

**Требования к образцу:**

- В записи звучит только один человек.
- Текст образца записан дословно, ударения в нём размечены так же, как в сценарии: он идёт в поле `"ref"`
  файла `in.json`.
- В конце образца — 0,45 с тишины.

Синтез своим голосом: `python ../synth.py my`. Скрипт ищет файл `ref-my-p.wav` и делает 3 дубля.

Если голос звучит не так, дело обычно в образце: шум, эхо, неточный текст или оборванная фраза. Меняют образец,
а не настройки синтеза. Для коммерческого заказа озвучку делают на Qwen3-TTS (Apache-2.0): она тоже клонирует
голос по образцу, но тембр передаёт хуже.

## Главная идея: один мастер-файл озвучки

Сценарий делится на четыре самостоятельных блока: **крючок → факт → поворот → панчлайн**. Озвучивается он
один раз, целиком. Разные монтажи получаются перестановкой кусков этого файла на таймлайне, перегенерировать
голос не нужно:

| Монтаж | Порядок блоков | Команда |
|---|---|---|
| линейный | 1 → 2 → 3 → 4 | `python build.py 1234 reel-linear` |
| с конца | 4 → 1 → 2 → 3 | `python build.py 4123 reel-from-end` |
| саспенс | 1 → 3 → 2 → 4 | `python build.py 1324 reel-suspense` |

Поэтому каждый блок должен читаться и без соседних: никаких «он», «это» и «потом» со ссылкой на предыдущую фразу.

## Пошагово

Рабочая папка для одного сюжета: подпапки `voice\` и `music\`, рядом с ними — все скрипты из приложения.

### 1. Сценарий

Написать 4 блока и источник факта. После **каждой** правки прогонять `python texts.py`: лимит строгий,
и текст на 61 слово при лимите 60 означает переозвучку.

### 2. Эталон голоса

```bash
echo "Утром на площади пусто: только голуби, лавочки и старый фонтан у входа в парк. К обеду здесь соберутся туристы и уличные музыканты." \
  | PYTHONIOENCODING=utf-8 piper --model ru_RU-dmitri-medium.onnx --output_file ref-dmitri.wav
ffmpeg -i ref-dmitri.wav -af "apad=pad_dur=0.45" -ar 24000 -ac 1 ref-dmitri-p.wav
```

0,45 с тишины в конце обязательны. Без них хвост последнего слова эталона просачивается в начало синтеза.

`PYTHONIOENCODING=utf-8` обязателен на Windows: без него Piper читает кириллицу в системной кодировке и озвучивает
мусор. Признак — образец выходит на 30–50 секунд вместо 8–10.

### 3. Ударения

Сценарий и текст эталона положить в `in.json` (`{"master": "...", "ref": "..."}`) и запустить:

```bash
python accent.py in.json master-acc.json
```

Результат проверить глазами. RUAccent путается в иностранных именах (Сигэру, Паули, Репербан) и иногда ставит
ударение на «не». Править прямо в `master-acc.json`. Аббревиатуры писать словами заранее: «пи-ди-эф».

### 4. Озвучка и отбор дубля

```bash
cd voice && python ../synth.py
```

Скрипт делает 6 дублей (2 голоса × seed 7/11/31). Каждый дубль распознаёт Whisper и сравнивает со сценарием,
результат пишет в `_сверка.json`. Из дублей со сверкой 1.0 выбрать лучший на слух и скопировать в `voice.wav`.

### 5. Таймкоды и границы блоков

```bash
python ../words.py voice.wav
```

Скрипт пишет `words.json` и печатает середины пауз после концов фраз. Эти числа вписать в `CUTS` в `build.py`
и проверить на слух. Whisper ставит начало слова чуть поздно, поэтому точная граница обычно на 0,1 с раньше
середины. Пример из «Поводка»: `CUTS = [0.0, 4.2, 11.45, 17.6, 22.4]`, последнее число — конец речи.

Субтитры строит `captext.py`: берёт слова **сценария** и раскладывает по таймкодам Whisper. Так пунктуация и регистр
остаются авторскими. Если число слов не сходится, скрипт останавливается: значит, озвучка разошлась с текстом.

### 6. Музыка и звуковые эффекты

```bash
cd music && python ../music_gen.py      # два варианта по текстовым промптам, ~27 с каждый
bash ../finish.sh music music-1.wav     # выбранный → music.wav на −18 LUFS
python ../sfx_lock.py                   # щелчок замка (пример эффекта)
```

MusicGen иногда даёт провалы громкости посреди трека. Перед выбором варианта проверить RMS кусками по 2 с.
В монтаже музыка идёт с `data-volume` около 0,22–0,24 под голосом.

### 7. Монтаж и рендер

```bash
python build.py 1234 reel-linear        # генерирует reel-linear/index.html и копирует туда звук
cd reel-linear
bash ../hf.sh lint
bash ../hf.sh snapshot --at 1.0,4.8,7.5,10.6,13.0,16.6,19.5,22.8 --describe false --no-end
bash ../hf.sh render -o renders/reel-linear.mp4 --fps 30 --quality looks --quiet
```

По `snapshot` проверить кадры до рендера: переносы строк, наложения, обрезанные штрихи. Рендерить только после этого.

Как устроен `build.py`:

- Сцены — это `div` с `data-start` и `data-duration`.
- Анимация — один GSAP-таймлайн `window.__timelines["main"]`.
- Голос — несколько `<audio>` с одним `voice.wav`, но разными `data-media-start`. Так и делается перестановка блоков.
- Субтитры, переходы и полоска прогресса подключаются из `polish.py`: `chunk_captions` режет текст блока на фразы
  (фраза не заканчивается предлогом или союзом), `capAnim2` показывает их по таймкодам, `outro` уводит сцену перед
  склейкой, `whoosh_wav` синтезирует звук перехода. Цвета задаются в `INK, ACCENT`.
- Визуальный язык примера: синька, сетка 40 px, шрифты Manrope и IBM Plex Mono, жёлтый акцент `#ffd23f`.

### 8. Постер и проверка

```bash
bash finish.sh poster reel-linear/renders/reel-linear.mp4 10.75 final-linear.mp4   # 10.75 — секунда кадра-постера
bash finish.sh check final-linear.mp4
```

Лучший «устоявшийся» кадр вшивается в кадр 0. Площадки показывают первый кадр как обложку, а в начале ролика сцена
ещё пустая. Финальная проверка: 1080×1920, 30 fps, громкость около −17 LUFS. Whisper по готовому миксу должен
распознать текст дословно, то есть музыка не забивает голос.

## Частые ошибки

- **У `<audio>` в HyperFrames обязателен `id`.** Без него звук молча пропадает из рендера.
- **JetBrains Mono не содержит кириллицы.** Моноширинный шрифт — IBM Plex Mono.
- **Whisper режет «Санкт-Паули» на два слова**, а тире распознаёт отдельным словом. `captext.py` их склеивает.
- **Длинные строки переносятся.** Кегль подбирать по `snapshot`, а не на глаз.
- **`stroke-dasharray` должен быть не короче контура**, иначе у анимированного штриха остаётся хвост.
- **Аксонометрию считать по передним граням**, иначе объём «выворачивается».

## Приложение: код скриптов

Каждый листинг сохранить в файл с именем из заголовка, в кодировке UTF-8, все файлы в корень рабочей папки.
Те же файлы вложены в PDF (панель «Вложения» в просмотрщике).

| `words.py` | 5 | пословные таймкоды и кандидаты в границы блоков |
