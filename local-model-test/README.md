# Справятся ли небольшие локальные модели с графикой

В пайплайне два места требуют «глаз»: нарисовать сцену (SVG и анимацию в `build.py`) и проверить кадры перед
рендером. Здесь проверено, может ли это делать локальная модель вместо большой облачной LLM.

Модели запускались в LM Studio. Доступа к файлам и командам у них не было: модель получает запрос через API
и возвращает текст, а запускает и рендерит всё скрипт.

## Тесты

**Тест 1. Найти дефекты вёрстки.** Четыре кадра из ролика «Поводок» в случайном порядке, `frames/`:

| Кадр | Что на нём |
|---|---|
| `A.png`, `D.png` | исправные кадры |
| `B.png` | заголовок «Генплан без туалетов —» обрезан краем кадра и налезает на вторую строку |
| `C.png` | крупная надпись «2 из 5» лежит поверх карты |

Каждый кадр проверялся двумя запросами: со строгим ответом в JSON и «сначала перечисли надписи, потом итог».

**Тест 2. Нарисовать сцену.** Модель получает пример сцены из `build.py`, стиль, раскладку кадра, текст диктора
и просьбу придумать свою визуализацию для «каждый пятый выходит из дома реже, чем хочет». Ответ вставляется
вместо блока 2 ролика и рендерится (`render_scene.sh`).

## Результаты

| Модель | Квант | Дефекты найдены | Своя сцена |
|---|---|---|---|
| Qwen3-VL-4B | Q4_K_M | 0 из 2; на исправном кадре выдумала ошибку | копия карты из примера, цифра налезает на текст, текст диктора продублирован вверху |
| Qwen3-VL-8B | Q8_0 | 0 из 2 | параметры анимации записаны строкой — GSAP падает, ролик целиком без анимации. После правки одной строки: перекрестье и кольцо, цифры «1 из 5» нет |
| Gemma 4 E2B | Q4_K_M | 0 из 2 | лучшая идея — круговая диаграмма с сектором, но сектор не пятая часть, «1 из 5» мелкое и пропадает, ошибка в коде гасит подсветку субтитров блока |
| gpt-oss-20b | MXFP4 | не видит картинок | скопировала служебную обёртку из примера в JS — скрипт не запускается. После правки работает: перекрестье и цифра, без смысловой картинки |
| Bonsai 27B | Q1_0 | 0 из 1 (проверено 2 кадра из 4) | не получена: обрывалась сеть, ответ 60–90 с |
| Qwen3.5-14B-A3B distill | — | не проверена | не проверена (обрывы сети) |

Что видно по всем моделям:

- **Читают отлично, оценивают плохо.** Все дословно переписывают надписи с кадра, включая обрезанное
  «Генплан без туал», и тут же пишут, что надпись «видна целиком».
- **Одна ошибка в коде сцены убивает анимацию всего ролика**, а не только своего блока: таймлайн GSAP общий.
  Сами модели такую ошибку не видят.
- **Своих визуальных идей почти нет**: копируют пример или рисуют абстрактные линии.

Вывод: локальной модели такого размера можно отдавать механику и заполнение готовых шаблонов сцен, но не рисование
и не проверку кадров.

В `results/<модель>/`: ответ модели (`scene.txt`), журнал теста (`log.md`), кадры и ролик — как есть и, где
сцена не работала, после правки одной строки.

## Как повторить

```bash
lms load qwen/qwen3-vl-8b -c 16384 -y                 # ровно один экземпляр модели
python run_tests.py qwen/qwen3-vl-8b res-vl8b          # без зрения: добавить --no-vision
bash render_scene.sh res-vl8b                          # кадры сцены в res-vl8b/gen/reel/snapshots
```

Сервер LM Studio ожидается на `localhost:1234`. При работе через LM Link связь может рваться. `run_tests.py`
в этом случае только ждёт и повторяет запрос: если в момент обрыва попросить загрузить модель, LM Studio
загружает вторую копию.
